PCom Assistant — Move to Another Windows Computer

1. Extract the ZIP file.
2. Install Node.js from https://nodejs.org if the new computer does not have it.
3. Copy .env.example and rename the copy to .env.local.
4. Open .env.local and add your DeepSeek API key after:
   DEEPSEEK_API_KEY=
5. Double-click start-local.bat.
6. Keep the black server window open.
7. Open the exact localhost address shown in that window, for example:
   http://localhost:3000

Important
- The API key is intentionally NOT included in this ZIP.
- Do not open index.html directly when using AI.
- If port 3000 is busy, the server will automatically try another port.
- Never upload .env.local to GitHub.

Move saved conversations and plans
1. On the old computer, open PCom Assistant and click Export.
2. Move the exported JSON file to the new computer.
3. Open PCom Assistant on the new computer and click Import.
