PCom Assistant API Key Setup

Double-click CREATE-ENV.bat.
It will create the required .env.local file and open it in Notepad.
Paste your DeepSeek key after:

DEEPSEEK_API_KEY=

Save the file, close Notepad, then double-click start-local.bat.

中文：
双击 CREATE-ENV.bat，它会自动创建 .env.local 并用记事本打开。
把 DeepSeek API Key 粘贴到 DEEPSEEK_API_KEY= 后面，保存并关闭，
然后双击 start-local.bat。
